# Sync Strike — ритм-файтинг под вашу музыку

Мобильная 2D-игра в браузере. Загрузите свой MP3: игра локально найдёт темп, доли, сильные доли и
кульминации трека и выстроит бой вокруг них. Стиль «Неоновая тень»: чёрные силуэты в масштабе
Hollow Knight с неоновым контровым светом.

**Запуск:** откройте `index.html` в браузере (Chrome, Safari, Firefox, Android и iOS). Сервер и
установка не нужны. Шрифты подгружаются с Google Fonts, без сети используются системные.

## Что внутри
- **Музыка:** загрузка MP3, плеер (пауза, повтор, перемотка, громкость), встроенный синтезированный демо-трек.
- **Анализ ритма** (только на устройстве): STFT и спектральный поток по трём полосам, темп через
  автокорреляцию, доли через динамическое программирование с удержанием фазы, сильные доли,
  секции по энергии, уверенность и режимы «точный / адаптивный / резервный».
- **Калибровка:** тап-тест на 12 касаний, метроном по аудиочасам, ручная задержка, чувствительность, ширина окон.
- **Бой:** одна кнопка атаки сама выбирает приём (кинжал «Нокс-9», рывок или выстрел «Импульс-7»)
  по дистанции, высоте и такту. Оценки Perfect / Good / Early / Late / Miss, подгонка удара к доле,
  буфер ввода, комбо-цепочка, связки «Эхо» и «Дуэт», пике с отскоком, замедление времени, идеальный уклон с контрударом.
- **Враги:** Клинок, Стрелок, Вихрь, Молот. Бьют в такт и подают сигнал перед атакой. Распределитель
  атак не допускает ударов со всех сторон одновременно.
- **Арены:** 6 штук (Неоновый город, Цифровая бездна, Литейный цех, Лунная крыша, Храм в тумане,
  Собор лучей). Подбираются под трек по признакам сигнала, выбор можно поменять вручную для каждого трека.
- **Облик:** 6 скинов игрока; враги появляются в разных вариантах снаряжения.
- **Управление:** мультитач-джойстик и кнопки, размер и прозрачность настраиваются, есть редактор раскладки.
  На ПК: клавиатура и мышь.
- **Режимы:** «Волны» (6 волн), «До конца трека», «Практика» с пошаговыми подсказками.

## Разработка
Исходники разбиты на модули в `src/js/` (Game, InputManager, AudioManager, RhythmAnalyzer,
RhythmClock, Player, Enemy, CombatSystem, AnimationSystem, ParticleSystem, ArenaRenderer, UIManager…).
`index.html` собирается из них командой:

```
node tools/build.js
```

Тесты (нужны Node и Playwright):
- `node tools/test-analyzer.js` — точность анализатора на демо-треке с известными долями;
- `node tools/smoke-test.js`, `node tools/screens-test.js`, `node tools/bot-test.js` — прогон в headless Chromium.

Проектный документ: [`docs/DESIGN.md`](docs/DESIGN.md).

## Известные ограничения
- Анализ ритма даёт оценку, а не идеальный результат. Свободный темп, рубато и тихие эмбиент-треки
  переходят в резервный режим с широкими окнами.
- На iPhone нет Fullscreen API и блокировки ориентации; вместо них работает оверлей «поверните устройство».
  При включённом беззвучном режиме iPhone звук Web Audio не играет.
- Задержка Bluetooth-наушников в браузере определяется неточно, поэтому есть тап-калибровка.
- Длинные треки (8+ минут) на слабых телефонах анализируются 10–20 секунд и занимают заметно памяти.
